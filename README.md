# FancyCam
An addon for Sonic Robo Blast 2 (v2.2), that modifies the default third person camera in **most** instances to be more fancier than the regular in-game one, allowing for a more interesting curated experience.

# Prerequisites
To be able to experience this, you must have Sonic Robo Blast 2 installed on the device you wish to play on. I recommend v2.2.15 and greater, since this script was written with these versions in mind.

# Installation
1. When available, download the latest version from the "Releases" tab. 
2. Then move the file over to your "SRB2/addons" directory. 
3. Finally, open the game and add the file via the Addons Option in the main menu, or through the console if you so wish.

# ⚠️ WARNING ⚠️
The camera will only apply in third person when in 3D sections of the area you are in. In 2D sections and first person, the modifications to what has been done to the camera will not apply, as to avoid any errors appearing in the console.
